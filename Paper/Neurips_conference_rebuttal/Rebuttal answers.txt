2. Clarity Issues: The learning mechanism, including the loss function of the proposed method, is unclear. Some symbols are unexplained. It is unclear what the model (backbone network) in the study is, including its trainable parameters, the usage of pretrained weights, and so on.

We apologize if the learning protocol was not sufficiently clear. Our work considers the standard fully online supervised learning setting. Unlike conventional supervised learning, there is no train/test split or multiple training epochs. Instead, data arrives as a continuous stream. For each incoming batch, the model first predicts the labels and the prediction performance is immediately recorded (prequential evaluation). The model then performs exactly one gradient update on the incoming batch using a standard cross-entropy loss. After this update, the samples remain temporarily in the FIFO support buffer to provide context for future predictions.

QOA introduces no additional optimization objective, auxiliary loss, or regularization term. The support buffer is not replay memory and is never used for additional training. It simply stores the most recently observed samples, which are concatenated with the current incoming batch to provide the context required for query-support matching during prediction.

The backbone architecture, trainable parameters, optimizer, and implementation details are described in Section D. All models are trained end-to-end from scratch with no pretrained weights. All trainable parameters, including those of the backbone and QOA, are updated through standard backpropagation using the same cross-entropy loss or squared error loss in case of regression.

1.How does QOA differ functionally from a matching network (Vinyals et al., 2016) or prototypical network (Snell et al., 2017) applied to this setting? Have you compared against these directly?

We agree that QOA is functionally closely related to metric-learning methods such as Matching Networks. This similarity is expected rather than accidental. Our contribution is not to propose a fundamentally new metric-learning architecture, but to explain how such a mechanism naturally emerges from progressively simplifying the standard attention computation.

Our motivation was inspired by recent work showing that full attention naturally mitigates loss of plasticity in fully online continual learning without relying on explicit plasticity-preserving mechanisms such as replay, selective reinitialization, or specialized regularization, while leaving the underlying reason unexplained. We therefore asked a different scientific question: what is the minimal computation within attention responsible for this behavior?

Starting from standard attention, we progressively simplified the computation and found that the key and value projections are not necessary to preserve the plasticity benefits. This derivation naturally yields Query-Only Attention (QOA) and reveals that the essential computation is query-support similarity, establishing a close connection between attention and metric learning. We view this connection as a scientific insight rather than a limitation. While metric-learning methods have primarily been studied for few-shot learning and rapid adaptation, their role in preserving plasticity during long-horizon fully online continual learning has received comparatively little attention.

More broadly, our work provides a mechanistic explanation for why similarity-based methods preserve plasticity. In conventional neural networks, each new task distribution is accommodated by continually modifying the model parameters. Over long non-stationary streams, these continual parameter updates progressively specialize the parameters to successive task distributions, reducing the model's ability to rapidly adapt to future tasks and ultimately resulting in loss of plasticity. In contrast, similarity-based methods learn a shared similarity function that is reused across tasks. Once this shared solution has been learned, adaptation relies primarily on query-support matching, requiring substantially smaller parameter updates. Figure 2(b) supports this hypothesis: vanilla backpropagation continues to exhibit large parameter changes throughout training, whereas both full attention and QOA rapidly reduce parameter updates as they converge toward a shared solution, thereby mitigating loss of plasticity.

Our contribution is therefore not proposing a fundamentally new metric-learning architecture, but deriving this connection from attention, providing a mechanistic explanation for why similarity-based inference preserves plasticity, and demonstrating its effectiveness in fully online continual learning.

Regarding the reported regret values, our regret is a relative cumulative regret, computed as the cumulative excess prediction loss with respect to the best-performing method at each timestep. Methods that adapt more slowly accumulate larger excess prediction errors immediately following distribution shifts, resulting in higher cumulative regret. Conversely, methods that rapidly adapt remain close to the best-performing method throughout the stream and therefore accumulate little or no excess regret.

In contrast, QOA adapts more rapidly, remains close to the best-performing method throughout training, and consequently exhibits near-zero relative cumulative regret. Thus, prequential accuracy reflects average online prediction performance, whereas relative cumulative regret summarizes the cumulative cost of slower adaptation over the entire stream.

4. What happens if QOA has no buffer (support set = only current sample)? This would isolate whether performance comes from the learned similarity or from buffer-based retrieval.

This ablation is already included in Section 6.1 ("Ablation Study: Effect of Buffer Size"), where we evaluate QOA with a support set containing only the current sample (buffer size = 1). As shown, performance degrades substantially compared to larger support buffers.

Importantly, the support buffer is not a replay buffer, but it is the attention context. Just as an attention model predicts the current token by attending to a context sequence, QOA predicts the current sample by attending to a small support set of recently observed samples. The support set is therefore part of the model's input, not additional training data. Each sample is updated exactly once when it first arrives and is never trained again. Afterwards, it only serves as attention context for future predictions until it leaves the FIFO buffer.

Moreover, this attention context is very small relative to the data stream. Thus, the observed improvement arises from using a small attention context rather than repeatedly training on stored examples.

5.The global solution argument applies to any classifier on a shared label space. Can you articulate specifically what is different about QOA's optimization landscape that makes convergence faster or more reliable than vanilla backpropagation?

The distinction is not that QOA optimizes a different loss, but that it learns a fundamentally different function than a conventional classifier.

A conventional neural network learns a direct input-to-label mapping, y=f_θ(x). Consider Permuted MNIST, where the same digit appears under a different pixel permutation in each task. Although the semantic label remains unchanged, the input distribution changes from task to task. Consequently, the model must continually modify its parameters to represent each new input-to-label mapping, leading to repeated parameter specialization over long streams.

In contrast, QOA does not directly map an input to its label. Instead, it learns a similarity function between the current query and support examples. The network outputs similarity scores, and the final prediction is obtained by aggregating the labels of the support examples according to these scores. Across Permuted MNIST tasks, while the pixel permutations change, the function being learned does not: the model is always required to assign higher similarity to support examples representing the same digit than to support examples representing different digits. Thus, adaptation occurs through the current support context during the forward pass rather than by continually relearning a new classifier. As a result, the model parameters converge toward a shared similarity function rather than repeatedly encoding task-specific input-to-label mappings. This reduces continual parameter drift, consistent with Figure 2(b), which shows substantially smaller parameter changes between consecutive tasks for QOA than for a conventional neural network.

2. Only the loss of plasticity is addressed, but actually continual learning is about ensuring plasticity-stability balance

We respectfully believe this comment conflates conventional continual learning with the fully online continual learning setting considered in this work. In conventional continual learning, the objective is often to balance stability and plasticity because performance is repeatedly evaluated on previously seen tasks. In contrast, fully online continual learning follows a prequential protocol: each sample is observed exactly once, the model first predicts its label, performs a single training update, and the sample is never seen again. Performance is therefore measured by prequential accuracy rather than repeated evaluation on previous samples.

Our setting assumes an effectively infinite stream of tasks with a finite label space. Each task defines a temporary data distribution (e.g., a subset of CIFAR-100 classes with a particular noise level) and generates a fixed-length sequence of samples before the stream moves to the next distribution. The same semantic class (e.g., "truck") may appear repeatedly under different input distributions, but identical samples are never revisited.

Accordingly, the primary challenge in this setting is not only preserving plasticity but also adapting rapidly to each new distribution. Since the stream consists of a large number of short-lived tasks (e.g., 10,000 tasks over the course of the stream), each task occupies only a very small fraction of the overall training time before the distribution changes again. Slow adaptation therefore results in poor prequential performance because the model spends most of each task learning rather than making correct predictions. Consequently, preserving plasticity and enabling rapid online adaptation are the central objectives in this setting, which is why we evaluate prequential accuracy and cumulative regret.
